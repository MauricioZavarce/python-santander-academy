# 🐍 Introdução ao Python - Santander Academy

Repositório criado para documentar minha jornada no curso de **Introdução ao Python** oferecido pelo **Santander Academy**.

Aqui você encontrará os exercícios práticos, projetos desenvolvidos e anotações importantes sobre os conceitos aprendidos durante o curso.

## 🎯 Objetivos do Curso

- Compreender os fundamentos da linguagem Python
- Aprender sobre variáveis, tipos de dados e operadores
- Dominar estruturas de controle (condicionais e laços de repetição)
- Trabalhar com funções, listas, dicionários e tuplas
- Desenvolver os primeiros projetos práticos

## 📚 Conteúdo do Repositório

## 🛠️ Tecnologias Utilizadas

- **Linguagem:** Python 3.x
- **Editor:** VS Code 
- **Controle de versão:** Git & GitHub

## 💻 Como Executar os Exercícios

1. Clone este repositório:
   ```bash
   git clone https://github.com/SEU-USUARIO/introducao-python-santander-academy.git
   ```
2. Acesse a pasta desejada:
   ```bash
   cd introducao-python-santander-academy
   ```
3. Execute qualquer arquivo Python:
   ```bash
   python nome_do_arquivo.py
   ```
